How to read this

  • CSI (critical success index) = forecast-right rain ÷ (forecast-right + not forecast + false alarm). 1 is perfect, 0 means none of the rain was where the forecast said. Dry areas that were correctly forecast dry don't count, so a mostly-dry day doesn't look falsely good.
  • Position tolerance forgives a rain area that arrived a little to the side. With 0 km, a shower forecast 5 km off counts both as a miss and as a false alarm.
  • Forecast made … ahead is counted from the model's start time. FMI publishes each run about 2–3 hours after its start, so the youngest forecasts were never actually available that early.
  • Satellite clouds are the Meteosat infrared picture from the middle of the hour. Seen from the equator, a high cloud over Finland appears 20–40 km too far north, so each cloud is moved back to its true position using EUMETSAT's cloud-top-height product. Lapland is seen at a very low angle, so the picture there is blurrier.
  • Forecast: FMI MEPS weather model, a new run every 3 hours. Observed: FMI radar composite, 1-hour rain. Data: Finnish Meteorological Institute open data, CC BY 4.0; satellite © EUMETSAT. Updated hourly.
